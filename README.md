# Meghna Jayanarayanan — Working Portfolio

This repository contains the new working version of Meghna's Architecture and BIM portfolio.

## Portfolio structure

- Home
- My Story — two reserved chapters
- Skills
  - Model
  - Coordinate
  - Collaborate

Each skill is understandable from the main Skills page and has its own detailed page.
